呪文の練習場のしくみ

声で唱えた呪文を、ブラウザの中だけで読み解いて、3Dの魔法にして飛ばしています。サーバーも AI の言語モデルも使っていません。このページでは、その中身を順に説明します。

色の付いた2つだけがブラウザの外の機能（マイクと音声認識）で、あとはすべてページの中の JavaScript で動いています。全体で HTML 1枚です。

一声を文字にする

Chrome に組み込まれている音声認識（Web Speech API の SpeechRecognition）を、日本語（ja-JP）で使っています。

  • 途中経過も受け取る（interimResults）。話している間も文字が届くので、その時点の呪文で魔法陣の色と大きさを変えています。
  • 候補を3つもらう（maxAlternatives = 3）。聞き違いに備えて、3つの候補のうち効果が見つかったものを使います。
  • 話し終わる（無音になる）と確定し、発動します。

Chrome の音声認識は、通常、音声を Google のサーバーに送って文字にしています。このページが外に送るのはこの音声だけです。文字で唱えた場合は、どこにも送りません。

二文字をそろえる

同じ呪文でも、音声認識はカタカナ、ひらがな、全角、半角をばらばらに返します。そこで、比べる前に次の順で形をそろえます。

NFKC 正規化（全角英数・半角カナを統一）→ 小文字 → カタカナをひらがなへ
例：「ファイア」→「ふぁいあ」

三対象と強め語を抜き出す

先に「誰に」と「どれくらい強く」を表す語を探し、見つけた語は伏せ字（＿）にして、効果の探索から外します。たとえば「あか」が火の効果に引っぱられないようにするためです。

種類語の例意味
対象あか・あお・みどり、右・左・真ん中、全員、仲間、自分、リオ・オルド・ミラ当てる相手
強め語大いなる、究極、古の、我が名、盟約、終焉、奥義 など威力が上がる
弱め語ぷち、ちょっと、少し、軽く など威力が下がる

対象を書かなければ、攻撃は向かいのかかしに、回復やバリアは唱えた本人にかかります。

四効果を探す（文字の並びで比べる簡易ベクトル検索）

効果は40種類あり、それぞれに呼び名の一覧（例：ファイアボールなら「炎、火、ふぁいあ、ほのお…」）を持たせています。呪文と呼び名を、2文字ずつの組（バイグラム）に分けて比べます。

呼び名「ふれいむ」 → ふれ / れい / いむ
呪文「ふれいみんぐ」→ ふれ / れい / いみ / みん / んぐ
一致 2組 ÷ 呼び名 3組 ＝ 0.67
  • 呼び名の組のうち、呪文に含まれる割合を点数にします。言い間違いや伸ばし棒の違いがあっても、半分以上合っていれば拾えます。
  • 短い呼び名ほど偶然当たりやすいので、重みを下げます（漢字1字は0.75、かな1字は0.4、2字は0.85、3字以上は1）。
  • 効果ごとに一番よい点数を取り、0.6以上なら採用します。1つもなければ詠唱失敗です。

意味まで分かる本物のベクトル検索（文の埋め込み）は、ブラウザで動かすと100MB級のモデルの読み込みが必要になるため、軽さを優先してこの方式にしました。文字の一致だけを見るので、「天」が入っていると聖なる光も出る、のような意外な組み合わせも起きます。

五威力を決める

長くて凝った呪文ほど派手になるよう、次の式で点数を出し、5段階にします。

点数 ＝ 文字数 ÷ 6 ＋ (区切りの数 − 1) × 0.8 ＋ 見つかった効果の数 × 0.9
       ＋ 強め語の数 × 1.3 − 弱め語の数 × 2.2
威力 ＝ 1 ＋ ⌊点数 ÷ 2.2⌋（1〜5に収める）
威力大きさの倍率同時に出す効果演出
★10.6倍1つ
★20.85倍2つまで
★31.1倍2つまで爆発などで画面が光る
★41.45倍3つまで発動の瞬間に画面が光り、揺れる
★51.9倍3つまで一瞬スローになり、対象を書かなければ全員に当たる

六溜めと発動

  • 溜め：唱えはじめると、足元に魔法陣が回り、杖の先へ光の粒が集まります。途中の文字から効果が見つかると、その属性の色に変わり、威力に合わせて魔法陣が大きくなります。
  • 発動：杖の先に小さな魔法陣が開き、効果ごとの処理が動きます。複数の効果は0.55秒ずつずらして出し、全員が対象なら0.12秒ずつずらします。
  • 詠唱失敗：杖の先で小さく爆発し、煙が出て、体が煤け、帽子が飛びます。

七3Dの描き方

描画は three.js（WebGL）です。人物も舞台も、円すいや球などの基本の形を組み合わせて作っていて、外から読み込むモデルや画像はありません。

  • 光の粒：6,000個と1,500個の点の束を2つだけ用意し、使い回しています。加算合成で描き、寿命に合わせて色を黒へ近づけると、黒は加算しても何も足さないので、自然に消えて見えます。
  • 煙・絵文字・文字（バナナ、ハート、「ゴーン!」など）：板に描いた絵（スプライト）を、上がったり落ちたりさせながら薄くしていきます。絵はページの中で Canvas に描いて作っています。
  • 魔法陣：円、六芒星、模様を Canvas に描いた1枚の絵を、色を変えて床や杖の先に重ねています。
  • 光：点光源を6個だけ置き、必要なときに一番古いものを借りて光らせます。光の数を増減すると描画の準備をやり直すことになり、カクつくためです。
  • 状態の変化（カエル、石化、巨大化、浮遊、眠りなど）：毎フレーム、かかっている状態をすべて見て、色・大きさ・高さ・傾きを合成します。始まりと終わりは0.25〜0.4秒かけてなじませます。
  • 時間：効果を進める「ゲームの時間」と、画面の「実際の時間」を分けています。時よ止まれ はゲームの時間をほぼ止めて画面を白黒にし、★5のスローは一瞬だけゲームの時間を遅くします。
